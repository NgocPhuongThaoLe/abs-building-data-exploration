## Unit interpretation

Convert a stored observation to its base unit using:

Base-unit value = OBS_VALUE × 10^UNIT_MULT

For example:

- OBS_VALUE = 12,673,855.0
- UNIT_MEASURE = AUD
- UNIT_MULT = 3

This represents 12,673,855 thousand AUD,
equivalent to 12,673,855,000 AUD.

For NUM with UNIT_MULT = 0, the stored value is already
a count in units.

Do not combine monetary values and dwelling counts.

## Missing values

| Column | Missing values |
| --- | ---: |
| OBS_VALUE | 48 |
| OBS_STATUS | 504 |
| OBS_COMMENT | 552 |
| All other columns | 0 |

All 48 missing OBS_VALUE rows have OBS_STATUS = m.
Metadata defines m as “not recorded”.

All 504 populated OBS_VALUE rows have a blank status.

The status identifies the observations as not recorded,
but does not explain why those specific values were not recorded.

Preserve missing observations as missing rather than replacing
them with zero.

Blank status or comment fields alone do not demonstrate a data error.
