# BA_SA2 — Data Dictionary

## Scope and source

This dictionary covers the BA_SA2 2.0.0 sample:
162 rows, 14 columns, and July–September 2023.

Code meanings were verified against the supplied ABS SDMX
structure XML file `2.0.0`.

Data types reflect the pandas output from the current sample.

## Unit interpretation

Convert a stored observation to its base unit using:

Base-unit value = OBS_VALUE × 10^UNIT_MULT

Examples from the sample preview:

| OBS_VALUE | UNIT_MEASURE | UNIT_MULT | Interpretation |
| ---: | --- | ---: | --- |
| 3978.0 | NUM | 0 | 3,978 dwelling units |
| 1192007.4 | AUD | 3 | 1,192,007.4 thousand AUD, equivalent to 1,192,007,400 AUD |

Do not combine dwelling counts and monetary values.

All 162 observations contain numeric values.

No status codes or observation comments are populated in this sample.
Blank status fields do not establish that observations are final
or unrevised.

OBS_STATUS and OBS_COMMENT are inferred as float64 because they
are entirely missing; this does not describe their intended
semantic data types.

The metadata defines status codes in CL_OBS_STATUS.
For example, m means “not recorded”, but this code does not
appear in the current BA_SA2 sample.

## Analysis considerations

- Select one measure and sector before analysing observation values.
- Keep counts and monetary values separate.
- Apply unit multipliers when converting values to base units.
- Avoid combining totals with their component sectors or regions.
- Align monthly periods with quarterly periods before comparing
  with BUILDING_ACTIVITY.
- Confirm measure definitions and aggregation rules before comparison.
- Do not assume approval values and construction activity values
  represent the same event or time period.
